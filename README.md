# Best Hand — Bionic Hand Design and Simulation

## Overview

**Best Hand** is a bionic hand project combining 3D mechanical design using SolidWorks with modeling and simulation using MATLAB/Simulink. The project focuses on designing and assembling a robotic hand and exploring its potential mechanical behavior through simulation.

## Objectives

- Design a 3D bionic hand using SolidWorks.
- Assemble individual mechanical components into a complete hand model.
- Develop a simulation model using MATLAB/Simulink.
- Explore robotic hand mechanisms and movement through simulation.

## Tools and Technologies

- **SolidWorks** — 3D mechanical design and assembly.
- **MATLAB/Simulink** — Modeling and simulation.
- **STEP** — Standard format for exchanging 3D CAD models.

## Repository Contents

| File / Format | Description |
|---|---|
| `.SLDPRT` | Individual SolidWorks mechanical parts. |
| `.SLDASM` | Assembly of the bionic hand. |
| `.STEP` | Exported 3D CAD models. |
| `BestHand.slx` | MATLAB/Simulink simulation model. |
| `biyonikEl_DataFile2.m` | MATLAB script associated with the model. |
| `.xml` | Supporting model data. |

## Project Goal

The goal of this project is to combine mechanical CAD design and simulation to explore bionic hand mechanisms, joint movement, and potential robotic control applications.

## Project Status

The repository contains the SolidWorks design files and MATLAB/Simulink simulation files. The simulation has not yet been verified in the current development environment.
